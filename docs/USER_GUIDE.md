# 译隙使用说明

## 开始练习

点击菜单栏“翻译”，或按 `⌘L`。首次在偏好设置中保存自己的 DeepSeek API Key，并测试连接、选择可用模型。选择方向、主题、难度和考试表达偏好后，卡片每次显示一个短句。

输入译文后按回车提交。中文输入法的候选尚未确认时，回车只确认文字；Shift 回车换行。评分完成后按回车换题，`⌘E` 修改再提交。未提交的草稿不会被“下一句”覆盖。网络失败时原题和草稿保留，不产生有效成绩记录。

## 评分明细

`⌘I` 在固定大小卡片内打开明细。三个分类是“纠错 / 对照 / 更多”，可点击或用左右键、`⌘1 / ⌘2 / ⌘3` 切换。上下键小幅滚动，Page Up / Down、空格 / Shift 空格滚动较长一段，Home / End 到首尾。Esc 或 `⌘I` 返回反馈。

参考译法不是唯一答案。内容 / 语法 / 自然表达 / 书写满分分别为 60 / 20 / 15 / 5；AI 可能判断有误，应结合扣分理由阅读。旧十分制记录不换算，也不与新版百分制混算。

## 历史记录

独立记录窗口可查看首次提交和修改记录；完成句数只算每题首次，修改次数另计。可导出 CSV、删除单条或批量删除，清空全部需界面确认。`⌘Z` 可撤销最近 20 批删除；撤销栈在退出后清空。删除练习记录不删除当前草稿、设置或实际接口调用记录。

## 提醒与联网材料

默认每 60 分钟浮现卡片，不抢焦点，15 秒后收起；按 `⌘D` 延后 30 分钟。只在程序运行时提醒，锁屏或息屏期间暂停，没有安装系统后台服务。

“联网找题”默认开启，可以关闭或手动补充；受每日预算及冷却限制。它补充公开参考材料，不等于下载整份题库。来源显示为真题节选、改编练习或原创仿题。雅思材料用于阅读 / 写作表达参考，不是翻译考试原题。源网页可能变更，目录记录的核对日期是历史快照。

## 备份与恢复

1. 退出译隙。
2. 把 `~/Library/Application Support/TranslateGap/` 整个文件夹复制到其他位置。
3. 恢复前先备份目标电脑的当前文件夹，再用完整备份替换该目录。
4. 重新打开译隙；Key 不包含在文件备份内，必要时重新配置。

`state-backup.json` 是上一份有效状态，会在保存时轮换，不替代独立备份。CSV 不是完整状态备份，也没有 CSV 恢复入口。不要在应用运行时替换状态文件。应用与词隙使用不同数据目录，不互相修改。
